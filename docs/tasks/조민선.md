## 운영자 CMS 사용법 (시나리오를 화면에서 만들고 고친다)
- 화면 오른쪽 위 **운영자** → 토큰 입력(장우석에게 개인적으로 받기) → 시나리오 목록
- **기존 시나리오 복제**로 새 시나리오를 시작할 수 있다 (오피스 화재 → 학교 지진 등)
- 탭: 기본 정보 / 배경·캐릭터 / 단계 / 평가·출처 / JSON(고급). 고칠 때마다 자동 검사 → **오류가 0개여야 저장·공개**
- **미리 플레이**로 공개 전에 직접 해 볼 수 있다. 새 시나리오는 '작성 중'이라 이용자에게 안 보인다
- 저장하면 `data/scenarios/<id>.json` 파일이 바뀐다 → 평소처럼 **브랜치 → PR** 로 올린다
