# 조민선 — 시나리오 콘텐츠 · 안전교육 조사 · 검증

**담당 파일:** `data/scenarios/*.json`
**결과물:** `docs/research/안전교육_조사.md`, `docs/research/검증케이스.md`, (4주차) 비용 계산표·발표 자료

## 왜 이 일이 중요한가
시나리오는 **하네스의 핵심 재료**다. AI는 시나리오를 보고 연기하고, 서버는 시나리오 규칙으로 단계를 진행한다.
정답 기준(`correct_action`)이 틀리면 잘못된 안전 지식을 가르치게 되므로, **공공기관 행동요령 근거**가 반드시 있어야 한다.
또 "문제: 안전교육은 영상 시청 위주"라는 문제 정의가 **진짜인지 보여 줄 근거**를 찾는 것도 이 역할이다.

## 먼저 볼 것
- `data/scenarios/README.md` (작성 가이드) → `data/scenarios/fire_office.json` (예시)

## 3주차 (11/16 ~ 22)

### 1. 화재 시나리오 검수 (가장 먼저)
- [ ] 국민재난안전포털·소방청의 **화재 행동요령 원문**을 찾아 `fire_office.json` 의 5단계 `correct_action` 과 하나씩 대조
  - 틀리거나 빠진 내용 → JSON 수정
  - `sources` 의 `url` 을 실제 페이지 주소로 바꾸고 `note` 의 TODO 지우기
- [ ] 각 단계 `keywords` 에 **사람들이 실제로 말할 법한 표현** 추가 (예: "계단" 외에 "비상구 쪽으로", "걸어서 내려가")
  - 친구 2~3명에게 단계 상황만 보여 주고 "뭐라고 말할래?" 물어보면 좋은 재료가 된다

### 2. 안전교육 시장 조사 → `docs/research/안전교육_조사.md`
- [ ] 학교·회사에서 안전교육을 **실제로 어떻게 하는지** (법정 의무 교육 여부, 시간, 방식: 영상/강의/훈련)
- [ ] 기존 교육의 한계를 보여 주는 근거 (기사·조사 자료, 출처 링크 필수)
- [ ] 돈을 낼 사람이 누구인지: 학교 / 기업 안전 담당 / 교육청 → 현재 쓰는 교육 서비스와 대략적인 가격
- [ ] 마지막에 **문제 한 줄 / 해결 한 줄** 초안 (지금 문장이 근거와 맞는지 점검)

> AI 활용 팁: "안전교육 현황 조사할 때 어떤 키워드로 검색하면 좋을까?"처럼 **검색 방향**을 묻는 데 쓴다.
> AI가 말한 통계·법 조항은 그대로 쓰지 말고 반드시 원문 링크를 찾는다. 못 찾으면 쓰지 않는다.
