# 김채희 — AI · 프롬프트 · 인젝션 방어

**담당 파일:** `backend/app/ai.py`, `backend/app/prompts.py`(새로 만들기), `backend/first_run.py`

서버는 `ai.py` 의 함수 3개만 부른다. 지금은 가짜 응답이 들어 있으니, **함수 이름 · 입력 · 반환 형식은 그대로 두고 안쪽만** 실제 API 호출로 바꾸면 된다.
반환 형식은 각 함수의 docstring에 적혀 있다. 형식을 바꿔야 하면 장우석과 먼저 상의.

| 함수 | 모델 | 하는 일 |
|---|---|---|
| `generate_cover_letter_questions(cover_letter, n=2)` | FAST | 자기소개서 기반 질문 2개 |
| `judge_followup(question, answer, history)` | FAST | 꼬리질문 필요 여부 + 질문 문장 |
| `evaluate(plan, transcript)` | SMART | 질문별 루브릭 점수 · 근거 · 개선점 |

## 2주차 (~11/15)
- [ ] `python first_run.py` 실행 → 결과 캡처 (1주차 첫 실행 확인 항목)

- [ ] `prompts.py` 에 시스템 프롬프트 작성 (면접관 역할 · 직무 · 한 문장 존댓말 · 정답 알려주지 않기)
- [ ] `judge_followup` 실제 호출로 교체 — **{need_followup, utterance} JSON만 출력**
- [ ] `evaluate` 실제 호출로 교체 — rubric 순서 · 개수 그대로, 점수 0~2
- [ ] `generate_cover_letter_questions` 실제 호출로 교체 (자기소개서가 비면 `[]`)
