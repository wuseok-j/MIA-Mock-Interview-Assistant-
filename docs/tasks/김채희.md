## 왜 이 일이 중요한가
멘토가 가장 중요하게 본 게 **하네스와 LLM 구성**이다. 서버는 "진행은 서버가 결정"하고, AI는 캐릭터 대사와 판정 *제안*만 한다.
AI가 얼마나 자연스럽게 말하고, 얼마나 안 속는지가 이 역할의 결과물이다.
또 이용자에 10대가 있을 수 있어서 **"우리는 아래로 가지 않는다"를 테스트로 증명**하는 것도 이 역할이다.

### 2. "행동이 일부만 맞았을 때" 대사 개선 ← 리허설에서 나온 가장 큰 개선점
- 지금: 1단계에서 "불이야"만 말하면 캐릭터가 항상 **"네가 말한 건 알겠어. 지금 내가 어떻게 움직이면 되는지 조금 더 구체적으로 말해 줘."** 라는 고정 문장을 말한다. 기계적으로 들린다.
- 이유: AI는 '정답'이라고 했는데 서버가 '아직 부족(119 신고가 빠짐)'으로 바꾸면, 서버가 시나리오의 고정 문장(`partial_reply`)으로 교체한다.
- [ ] `prompts.py` 에 **"이번 단계에서 아직 확인되지 않은 행동"**을 넘겨서, AI가 처음부터 '아직 부족'에 맞는 자연스러운 대사를 하게 만들기
  - 단, **정답을 직접 말하면 안 된다** ("119에 신고해" ✕ → "그래서 누가 신고는 하는 거야?" ○)
  - 무엇을 넘길지(데이터 형식)는 장우석과 먼저 정하기 — `harness.py` 가 넘겨줘야 하는 값이라서
