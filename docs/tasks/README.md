## 멘토에게 물어볼 것 (전원이 하나씩 준비)
- 배포: 무료 클라우드로 시연용 배포까지 해야 하는지, 로컬 시연으로 충분한지
- 로그인·결제: 프로토타입 단계에서 구현이 필요한지, 화면 설계·계획으로 충분한지
- AI: Gemini 무료 한도 안에서 시연해도 되는지 / 모델 선택 기준
- (각자 맡은 부분에서 막히거나 판단이 필요한 것 1개씩)

## 공통 규칙 (다시 한 번)

1. `main` 에 직접 push 금지 → 브랜치 → PR → **장우석이 확인 후 머지**. ([협업 가이드](../협업가이드.md))
2. 작업 시작·끝에 `docs/handoff/본인이름.md` 읽고 갱신. 남의 파일·`CLAUDE.md` 는 고치지 않는다.
3. 매일 단톡에 한 줄: **어제 한 것 / 오늘 할 것 / 막힌 것**. 30분 넘게 막히면 캡처해서 바로 질문.
4. **운영자 토큰(`ADMIN_TOKEN`)과 API 키는 단톡에 올리지 않는다.** 장우석에게 개인적으로 받는다.
5. AI가 만든 사실(통계·출처·행동요령)은 반드시 원문으로 확인. 멘토가 물으면 **내가 설명할 수 있어야** 한다.

## 실행 방법 요약

```powershell
# 터미널 1 — 백엔드 (backend 폴더)
.venv\Scripts\python -m uvicorn app.main:app --reload
# 터미널 2 — 화면 (frontend 폴더)
npm run dev
```
http://localhost:5173 → 이용자 화면 / 오른쪽 위 **운영자** → CMS. (`.env` 설정은 장우석에게)
