## 작업 방식

1. `main` 에 직접 push 하지 않는다. `feat/면접화면` 같은 브랜치에서 작업하고 PR로 합친다.
2. PR 리뷰는 맞닿는 사람이 본다. (API 변경 → 곽동규, AI 함수 → 장우석, 질문은행 → 김채희)
3. 할 일은 GitHub Issue 하나에 담당자 한 명. 아래 각자 파일의 체크박스를 Issue로 옮겨도 된다.
4. 매일 단톡에 한 줄: **어제 한 것 / 오늘 할 것 / 막힌 것**
5. 아래 파일의 체크박스는 끝날 때마다 각자 체크해서 PR에 같이 올린다.
