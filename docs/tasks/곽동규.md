# 곽동규 — 프론트엔드

**담당 폴더:** `frontend/`
**기준 문서:** `docs/api-spec.md` (요청 · 응답 형식)

서버 완성을 기다리지 말고, `api-spec.md` 의 응답 예시를 가짜 데이터로 써서 화면부터 만든다.
서버는 `cd backend && uvicorn app.main:app --reload` 로 띄우면 지금도 가짜 AI로 끝까지 동작한다. (http://localhost:8000/docs)

## 2주차 (~11/15)
- [ ] `frontend/` 에 Vite + React 프로젝트 생성 (`frontend/README.md` 참고)
- [ ] 화면 3개 뼈대와 화면 이동: ① 면접 설정 → ② 모의면접 → ③ 평가 리포트
- [ ] ① 면접 설정: 자기소개서 입력창(최대 2,000자, 글자 수 표시), '면접 시작' 버튼
- [ ] ② 모의면접: 질문 표시, 답변 입력(최대 1,000자), '답변 제출', 진행률(예: 3/5)
- [ ] ③ 평가 리포트: 총점, 질문별 점수 · 근거 · 개선점

## 3주차 (11/16 ~ 11/22)
