- Gemini 환경변수 준비 요청: 기존 .env 없음 확인 후 루트 .env 생성, .env.example 갱신. LLM_PROVIDER=gemini, GEMINI_API_KEY 빈칸, FAST/SMART 모델 후보 gemini-2.5-flash 설정. 기존 Claude용 LLM_API_KEY는 빈칸으로 분리.
- 이번 변경은 환경파일만 준비한 것. 현재 ai.py·first_run.py는 Claude 코드이므로 Gemini 호출 모듈 전환이 남아 있고, Gemini 키만 입력해도 현재 코드는 mock으로 동작함. 실제 키 입력·API 호출 미실행.
