# 작업 인수인계 (사람별)

AI 도구(Claude Code, Codex 등)를 새로 켜거나 다른 컴퓨터에서 이어서 작업할 때, **지난번에 어디까지 했는지** 알 수 있게 남기는 기록이다.

## 규칙

1. **각자 `docs/handoff/본인이름.md` 하나만 고친다.** 다른 사람 파일은 읽기만 한다.
   - 이유: 한 파일을 여러 명이 고치면 PR마다 충돌이 난다. 각자 자기 파일만 고치면 충돌이 생기지 않는다.
2. 파일이 없으면 처음 작업할 때 만든다. (AI 도구가 `CLAUDE.md` 규칙을 보고 알아서 만든다)
3. 작업을 마칠 때 갱신하고, 그 작업의 PR에 같이 올린다.
4. 실제로 한 것만 적는다. 실행하지 않은 검증은 "미실행"으로 적는다.

## 형식

```markdown
# 이름 — 인수인계

최종 갱신: 2026-11-16 / 브랜치: content/화재검수

## 지난 작업
- 무엇을 바꿨는지 (파일 이름과 함께)

## 검증
- 실행한 것과 결과 / 미실행인 것

## 다음에 할 것
- 다음 작업, 막힌 점, 누구에게 물어볼지
```

팀원별 할 일 목록은 `docs/tasks/`, 프로젝트 배경과 원칙은 루트의 `CLAUDE.md` 가 기준이다. 여기에는 **진행 기록**만 남긴다.
